# Records Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement records with row polymorphism for Wok, following `docs/superpowers/specs/2026-05-27-records-spec.md`. Adds record-form `data` decls (with name-elision sugar), `+` extension at the type level (concrete `{...}` rows and `row r` row variables), bidirectional construction, field access via `EProj`, strict/open pattern matching, the Leijen 2005 scoped-label row unifier, and a row-shadow warning on instantiation-induced label collisions.

**Architecture:** Extend the HM-core type representation with a nominal-tagged record carrier `TRecord Text (Row s)` / `CTRecord Text CRow`. Replace the `unifyRow` stub with the full Leijen 2005 algorithm (`rewriteRow` head-bubbling, occurs check on row variables). Add a record-only constructor descriptor that does NOT register a curried `conScheme`, making record constructors syntactic-form-only. Layout filter grows a brace-context stack so record `{ ... }` literals support both inline (comma-separated) and block-indented forms uniformly. Type-level `+` parses as a generic `VarSym` and is restricted to `"+"` in the elaborator, with `RowContrib ::= "row" VarId | "{" ... "}"` constraining what can follow.

**Tech Stack:** GHC 9.10 (GHC2024), `mtl`, `containers`, `text`, BNFC for the grammar, `tasty` + `tasty-golden` for tests. Inherits the `Strict`/`StrictData`/`-funbox-strict-fields` posture of the HM core.

- [ ] **Step 1: Create the layout pre-pass**

Create `src/Wok/RecordLayout.hs`. The strategy: a stream-level pre-pass over the token list, AFTER lexing but BEFORE the BNFC layout filter. Walk the stream tracking a stack of brace contexts. Each context records the column of the opening `{`. When the next token after `{` is on a new line indented past that column, the context is "block-layout"; otherwise it's "inline."

- [ ] **Step 1: Implement `bindRowVar` with occurs-check**

```haskell
-- | Bind a row variable to a row. Performs occurs-check.
bindRowVar :: SourceSpan -> STRef s (RVar s) -> Row s -> TC s ()
bindRowVar sp ref row = do
  rv <- liftST $ readSTRef ref
  case rv of
    RUnbound _ lvl -> do
      occursAdjustRowVar sp ref lvl row
      liftST $ writeSTRef ref (RLink row)
    RLink _ -> error "bindRowVar: caller must have forced first"

-- | Combined occurs check + level adjustment for row variables.
occursAdjustRowVar :: SourceSpan -> STRef s (RVar s) -> Level -> Row s -> TC s ()
occursAdjustRowVar sp target lvl = go
  where
    go RowEmpty = pure ()
    go (RowExtend _ ty rest) = occursAdjust sp ... lvl ty >> go rest
      -- (re-use existing occursAdjust; the row carries types now since records have non-empty rows)
    go (RowVar r)
      | r == target = throwError (OccursCheck sp 0 (CTGen 0))
      | otherwise = do
          rv <- liftST $ readSTRef r
          case rv of
            RLink r' -> go r'
            RUnbound u l ->
              when (l > lvl) $
                liftST $ writeSTRef r (RUnbound u lvl)
```

- [ ] **Step 2: Implement `rewriteRow` and `rewriteRowStrict`**

```haskell
-- | Bubble label `l` up to the head of `row`. On RowVar, ALLOCATE a fresh
-- type and tail; bind the var to RowExtend l fresh-ty fresh-tail. Returns
-- the type of the label and the remaining row.
rewriteRow :: SourceSpan -> Text -> Row s -> TC s (Type s, Row s)
rewriteRow sp l row = do
  row' <- forceRow row
  case row' of
    RowExtend l' t rest
      | l == l'   -> pure (t, rest)
      | otherwise -> do
          (t', rest') <- rewriteRow sp l rest
          pure (t', RowExtend l' t rest')
    RowVar ref -> do
      tFresh    <- freshTVar KStar
      restFresh <- freshRowVar
      bindRowVar sp ref (RowExtend l tFresh restFresh)
      pure (tFresh, restFresh)
    RowEmpty -> throwError (UnknownField sp (Tx.pack "<row>") l)

-- | Like rewriteRow but REFUSES to extend a row variable. Used for
-- field access (`p.x`): we want a clean error rather than silently
-- inferring `r` to contain the label.
rewriteRowStrict :: SourceSpan -> Text -> Row s -> TC s (Type s, Row s)
rewriteRowStrict sp l row = do
  row' <- forceRow row
  case row' of
    RowExtend l' t rest
      | l == l'   -> pure (t, rest)
      | otherwise -> do
          (t', rest') <- rewriteRowStrict sp l rest
          pure (t', RowExtend l' t rest')
    RowVar _ -> throwError (UnknownField sp (Tx.pack "<row>") l)
    RowEmpty -> throwError (UnknownField sp (Tx.pack "<row>") l)
```

- [ ] **Step 3: Replace `unifyRow`**

```haskell
unifyRow :: SourceSpan -> Row s -> Row s -> TC s ()
unifyRow sp r1 r2 = do
  r1' <- forceRow r1
  r2' <- forceRow r2
  case (r1', r2') of
    (RowEmpty, RowEmpty) -> pure ()

    (RowVar v1, RowVar v2)
      | v1 == v2 -> pure ()
      | otherwise -> bindRowVar sp v1 (RowVar v2)

    (RowVar v, row) -> bindRowVar sp v row
    (row, RowVar v) -> bindRowVar sp v row

    (RowExtend l1 t1 rest1, row2) -> do
      (t2, rest2') <- rewriteRow sp l1 row2
      unify sp t1 t2
      unifyRow sp rest1 rest2'

    (RowEmpty, RowExtend _ _ _) -> do
      cr1 <- freezeRow r1'
      cr2 <- freezeRow r2'
      throwError (RowMismatch sp cr1 cr2)
```

- [ ] **Step 2: Implement `inferRecordLiteral`**

The core checker. Per spec §"Construction inference":

```haskell
inferRecordLiteral
  :: BNFC'Position
  -> Map Text (Type s)                -- monos
  -> Maybe (Type s)                   -- expected type (bidirectional)
  -> RecordConInfo                    -- the constructor descriptor
  -> Maybe (Abs.Exp, Type s)          -- spread source, if any (for ERecordExt)
  -> [Abs.RecordFieldExpr]            -- trailing fields
  -> TC s (Type s)
inferRecordLiteral pos mono expected conInfo spread trailingFields = do
  -- 1. Determine the allowed-extras set from the expected type.
  --    If expected is Just (TRecord tag extRow) with tag matching conInfo.rcTag,
  --    extract the labels in extRow that aren't in declared fields.
  --    Otherwise, no extras allowed.
  let declared = Set.fromList [name | (name, _) <- rcFields conInfo]
  expectedExtras <- case expected of
    Just t -> do
      t' <- force t
      case t' of
        TRecord tag row | tag == rcTag conInfo -> labelsFromRow row >>= pure . (\\ declared)
        _ -> pure Set.empty
    Nothing -> pure Set.empty

  -- 2. Gather fields contributed by the spread (if any).
  spreadFields <- case spread of
    Nothing -> pure Set.empty
    Just (_, sT) -> do
      sT' <- force sT
      case sT' of
        TRecord tag row | tag == rcTag conInfo -> labelsFromRow row
        TRecord tag _ ->
          throwError (NominalMismatch pos (rcTag conInfo) tag)
        _ -> do
          fT <- freeze sT'
          throwError (NotARecord pos fT)

  -- 3. Each trailing field must be in declared OR in expectedExtras OR override
  --    a spread-contributed field.
  let allowedSet = declared <> expectedExtras <> spreadFields
  for_ trailingFields $ \(Abs.RFExpr (Abs.VarId (fpos, fname)) _) ->
    unless (Set.member fname allowedSet) $
      throwError (UnknownField fpos (rcTag conInfo) fname)

  -- 4. Each declared field of the constructor must appear, either in the
  --    spread or in the trailing fields.
  let providedSet = spreadFields <> Set.fromList [fn | Abs.RFExpr (Abs.VarId (_, fn)) _ <- trailingFields]
      missing = Set.difference declared providedSet
  unless (Set.null missing) $
    throwError (UnknownField pos (rcTag conInfo) (Tx.intercalate ", " (Set.toList missing)))
    -- (consider adding a dedicated MissingField error)

  -- 5. Type-check each trailing field's value.
  --    For declared fields, the expected type is the field's declared type.
  --    For extension fields (in expectedExtras), the expected type comes from the expected row.
  --    Canonicalization (line 241 of spec): if a trailing field overrides a same-label
  --    in the spread row or in another trailing field, types must unify.
  --    When the spread row contains a RowVar (opaque), we cannot detect collisions;
  --    treat the trailing field as a fresh add. (Substitution may introduce scoped
  --    labels at the call site; this is the Leijen design.)
  forM_ trailingFields $ \(Abs.RFExpr (Abs.VarId (_, fname)) e) -> do
    let expectedFieldT = lookupFieldType fname conInfo expected
    actualT <- inferExprWChecked mono (Just expectedFieldT) e
    unify (Just pos) actualT expectedFieldT

  -- 6. Build the result type:
  --    - If expected was Just (TRecord tag row) and tag matches, the row IS the result row
  --      (preserves any RowVar tail from the expected type).
  --    - If spread was present and no expected type, the result row is the spread's row
  --      with any override types updated.
  --    - Otherwise, the result row is the closed row of declared fields.
  let resultRow = ...   -- combine declared + spread + trailing + expected
  pure (TRecord (rcTag conInfo) resultRow)
```

```haskell
inferAtomPat (Abs.PRecord (Abs.ConId (pos, conName)) fieldPats) = do
  conInfo <- lookupRecordConOrFail pos conName
  -- Strict pattern: result type is a CLOSED TRecord (no row variable in tail).
  let declared = rcFields conInfo
      fieldMap = Map.fromList declared
  binds <- forM fieldPats $ \(Abs.RFPat (Abs.VarId (fpos, fname)) p) -> do
    let fieldT = Map.lookup fname fieldMap
    case fieldT of
      Nothing -> throwError (UnknownField fpos (rcTag conInfo) fname)
      Just cT -> do
        t <- ctypeToType cT
        (patT, patBinds) <- inferPat p
        unify (Just fpos) patT t
        pure patBinds
  -- Result type: closed TRecord with declared row.
  let row = foldr (\(n, cT) acc -> RowExtend n (cTypeToType cT) acc) RowEmpty declared
  pure (TRecord (rcTag conInfo) row, concat binds)

inferAtomPat (Abs.PRecordOpen (Abs.ConId (pos, conName)) fieldPats Abs.PRTAnon) = do
  conInfo <- lookupRecordConOrFail pos conName
  -- Open pattern: row has a fresh RowVar at the tail.
  freshTail <- freshRowVar
  binds <- forM fieldPats $ \(Abs.RFPat (Abs.VarId (fpos, fname)) p) -> ...
  let row = foldr (\(n, cT) acc -> RowExtend n ... acc) (RowVar freshTail) declared
  pure (TRecord (rcTag conInfo) row, concat binds)

inferAtomPat (Abs.PRecordOpen (Abs.ConId (pos, _)) _ (Abs.PRTNamed _ (Abs.VarId (_, binder)))) =
  throwError (NamedRowTailCaptureDeferred pos binder)

inferAtomPat (Abs.PRecordWild (Abs.ConId (pos, conName)) Abs.PRTAnon) = do
  -- Like PRecordOpen but with no explicit fields; just the open tail.
  conInfo <- lookupRecordConOrFail pos conName
  freshTail <- freshRowVar
  let row = foldr ... (RowVar freshTail) (rcFields conInfo)
  pure (TRecord (rcTag conInfo) row, [])

inferAtomPat (Abs.PRecordWild (Abs.ConId (pos, _)) (Abs.PRTNamed _ (Abs.VarId (_, binder)))) =
  throwError (NamedRowTailCaptureDeferred pos binder)
```

## Task 9: Row-shadow warning at substitution time

**Goal:** When row-variable instantiation introduces a label that already exists in the concrete part of the row, emit a `RowShadowWarning` at the call site. The program still typechecks; the warning is informational.

**Files:**
- Modify: `src/Wok/TypeChecking/Unify.hs` (detect the shadow case in `bindRowVar`)
- Modify: `src/Wok/TypeChecking/Infer.hs` (collect and propagate warnings)
- Add tests: `test/Spec.hs`

**Acceptance Criteria:**
- [ ] Calling `g1 : Point + row r -> Point + row r + { tag : String }` on `Point + { tag : Int }` emits a warning at the call site.
- [ ] The program compiles; the warning is informational.
- [ ] The warning text includes both types and is clear about the shadow.
- [ ] No warning when there's no collision.

**Verify:** `cabal test --test-options "-p \"RowShadow\""` → pass.

**Steps:**

- [ ] **Step 1: Threading warnings**

If `Warning` already exists in `Infer.hs`, add `RowShadowWarning Span Text CType CType` to it. If not, introduce a writer-like channel (the simplest: a `STRef [Warning]` in `TCState`).

- [ ] **Step 2: Detect the shadow in `bindRowVar`**

Before binding a row variable to a row, walk the row being bound (RHS) and collect every label. Walk the "context" row (the row the LHS-variable was inside) and collect labels too. Any label present in BOTH is a shadow.

The trick: at `bindRowVar` time, we have only the variable and the row to bind to. The "context" — what's above the variable in the larger row — is NOT directly accessible.

The cleaner place to detect this is in `unifyRow` itself, at the point where we encounter `(RowExtend l1 t1 rest1, row2)` and call `rewriteRow sp l1 row2`. If `rewriteRow` finds `l1` in the concrete part of `row2`, no shadow. If `rewriteRow` walks through `l1` already present and finds another in the row variable's instantiated tail, that's the shadow case.

Implementation: extend `rewriteRow` to track whether it traversed any concrete `l == l'` matches before reaching the RowVar:

```haskell
-- rewriteRow returns (label-type, remaining-row, didShadow).
rewriteRowS :: SourceSpan -> Text -> Row s -> TC s (Type s, Row s, Bool)
rewriteRowS sp l row = do
  row' <- forceRow row
  case row' of
    RowExtend l' t rest
      | l == l'   -> pure (t, rest, False)
      | otherwise -> do
          (t', rest', shadow) <- rewriteRowS sp l rest
          pure (t', RowExtend l' t rest', shadow)
    RowVar ref -> do
      tFresh    <- freshTVar KStar
      restFresh <- freshRowVar
      bindRowVar sp ref (RowExtend l tFresh restFresh)
      -- Check whether `l` appears anywhere in the *current* row chain that we
      -- already walked past — TODO this needs the "outer context."
      pure (tFresh, restFresh, False)
    RowEmpty -> throwError (UnknownField sp ... l)
```

Simpler approach: detect at the call site (where row-var instantiation happens) by comparing the substituted result row against itself for duplicate labels:

```haskell
-- After unification at a call site, walk the result row and emit a warning
-- for any pair of same-name RowExtend entries with non-RowEmpty separation.
warnOnRowShadow :: SourceSpan -> Type s -> TC s ()
warnOnRowShadow pos t = do
  t' <- force t
  case t' of
    TRecord _ row -> do
      labels <- collectLabels row
      let duplicates = findDuplicateLabels labels
      forM_ duplicates $ \(l, t1, t2) -> do
        ct1 <- freeze t1
        ct2 <- freeze t2
        addWarning (RowShadowWarning pos l ct1 ct2)
    _ -> pure ()
```

This runs after every application's return type is computed. (Or after let-binding's final inferred type, whichever is the natural call boundary.)

- [ ] **Step 3: Wire `warnOnRowShadow` into `inferExprW`'s `EApp`**

After computing the result type of an application, call `warnOnRowShadow`.
