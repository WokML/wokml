# M1.5 Closures / HOF in the Perceus RC Pass — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers-extended-cc:subagent-driven-development (recommended) or superpowers-extended-cc:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `insertRC` + `balanceLint` sound for ordinary closures (standalone `RLam`) and for local recursive groups that capture enclosing owned locals, so the RC interpreter's boundary guard stops rejecting higher-order programs.

**Architecture:** Treat a closure build as a heap allocation whose fields are its free captured variables (identical to `RCon`). The runtime half already exists (F4 `enterRC`); the pass mirrors it. One shared free-vars helper keeps the pass and the interpreter from drifting. Two phases in one branch: Phase 1 = standalone `RLam` (cell owns captures, body is its own owned scope); Phase 2 = `LetRec` enclosing-capture (region owns captures, member bodies borrow).

**Tech Stack:** Haskell (GHC), `cabal`, `tasty`/`HUnit` test suite `wok-tests`, modules `Wok.IR.Anf`, `Wok.IR.Perceus`, `Wok.IR.Reachable`, `Wok.Interp.RC.{Value,Machine}`, corpus `test/rc-examples/*.wok`.

ownRhs ctx sup (RLam ps e) =
  let params  = Set.fromList (map binderUnique ps)
      caps    = (freeVarsExpr e `Set.difference` params)
                  `Set.intersection`  -- only owned, non-exempt, boxed captures are owned in the body

ownRhs _ sup r = (sup, r)

Concretely, seed the body's owned set from the closure's boxed params plus its boxed captures, with a fresh env (params + captures + the enclosing env for name/type lookup), joins reset, exempt reset:

```haskell
ownRhs ctx sup (RLam ps e) =
  let params   = Set.fromList (map binderUnique ps)
      capsBoxed = Set.fromList
                    [ u | u <- Set.toList (freeVarsExpr e `Set.difference` params)
                        , Just b <- [Map.lookup u (ctxEnv ctx)], boxedBinder b ]
      psBoxed  = Set.fromList [ binderUnique p | p <- ps, boxedBinder p ]
      dDelta   = psBoxed `Set.union` capsBoxed
      dEnv     = foldr (\p -> Map.insert (binderUnique p) p) (ctxEnv ctx) ps
      dCtx     = Ctx dEnv Map.empty Set.empty
      (sup', e') = ownExpr dCtx sup dDelta e
  in (sup', RLam ps e')
ownRhs _ sup r = (sup, r)
```

```haskell

  ...  -- thread supR through the rest; emit 'Let b rhs' (projDup dropped)'
```

(The capture-move accounting in Step 4 used `ctxEnv` to find boxed-ness; here `capsBoxed` is the boxed subset captured in the body. These two must agree: a capture is moved at build iff it is in `delta`, and owned in the body iff boxed — in M1 every boxed owned local is in `delta`, so the sets coincide; see spec §4.7.)

- [ ] **Step 4: Instrument the group build with multiset dups + exempt captures.** In `ownExpr (LetRec defs body)`, compute the capture multiset across members, dup accordingly, add captures to each member body's exempt set, and move the captures out of the enclosing delta:

```haskell
ownExpr ctx sup delta (LetRec defs body) =
  let groupU   = Set.fromList [ binderUnique b | (b, _, _) <- defs ]
      groupBoxed = groupU
      -- per-member captured owned boxed non-exempt enclosing locals
      memberCaps (_, ps, dbody) =
        (freeVarsExpr dbody `Set.difference` Set.fromList (map binderUnique ps))
          `Set.intersection` delta
          `Set.difference` ctxExempt ctx
      capOcc   = Map.fromListWith (+)
                   [ (u, 1) | d <- defs, u <- Set.toList (memberCaps d) ]
      allCaps  = Map.keysSet capOcc
      laterBody = freeVarsExpr body
      need u    = Map.findWithDefault 0 u capOcc + (if u `Set.member` laterBody then 1 else 0)
      dupPlan'  = [ (u, need u - 1) | u <- Set.toList allCaps, need u - 1 > 0 ]
      -- captures are consumed by the region unless they survive into the LetRec body
      consumedCaps = Set.filter (`Set.notMember` laterBody) allCaps
      ctxIn    = ctx { ctxEnv    = foldr (\(b,_,_) -> Map.insert (binderUnique b) b) (ctxEnv ctx) defs
                     , ctxExempt = ctxExempt ctx `Set.union` groupU }
      onDef sp (b, ps, dbody) =
        let dEnv   = Map.fromList [ (binderUnique p, p) | p <- ps ]
                       `Map.union` Map.fromList [ (binderUnique g, g) | (g,_,_) <- defs ]
                       `Map.union` ctxEnv ctx
            -- member captures are BORROWED: exempt inside the body, never consumed
            dCtx   = Ctx dEnv Map.empty
                         (ctxExempt ctx `Set.union` groupU `Set.union` memberCaps (b, ps, dbody))
            dDelta = Set.fromList [ binderUnique p | p <- ps, boxedBinder p ]
            (sp', dbody') = ownExpr dCtx sp dDelta dbody
        in (sp', (b, ps, dbody'))
      (sup1, defs') = mapAccumLDefs onDef sup defs
      bodyDelta     = (delta `Set.difference` consumedCaps) `Set.union` groupBoxed
      (sup2, body') = ownExpr ctxIn sup1 bodyDelta body
      (sup3, dups)  = mkDupsForVars sup2 (ctxEnv ctx) dupPlan'
  in (sup3, foldr ($) (LetRec defs' body') dups)
```

(The dups are emitted *before* the `LetRec` so each capture carries `need u` owning units when the group is built; each capturing member's cascade decrefs one at the group drop; a surviving capture keeps its extra unit for the body. Member bodies treat captures as exempt — referenced freely, never moved/dropped — matching the region-exempt `consume` in `enterRC`.)
