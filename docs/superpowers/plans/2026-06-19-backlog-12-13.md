# Backlog #12 (APrim atom) + #13 (positioned generic-expression unifies) Implementation Plan

**Goal:** Close the last two 2026-06-12 backlog residuals — make a missing binder a loud `UnboundVar` instead of a silently-substituted builtin (#12), and attach source positions to generic-expression / `case` / pattern type-mismatch errors (#13).

**Architecture:** #12 adds a structurally-distinct `APrim Text` atom form, routes builtins to it by prelude-`extern` identity in the elaborator, and deletes the two by-hint prim fallbacks (reference `resolveAtom`, RC `callFn`). #13 extends the existing `expPos` leaf-walker, adds a `patPos` mirror, and feeds recovered positions into seven positionless `unify` sites. All work is on branch `fix/backlog-residuals-12-13`.

**Tech Stack:** Haskell (GHC, cabal), tasty / tasty-golden / tasty-hunit. The `common strict` cabal stanza is `-Wall -Werror -Wincomplete-patterns -Wincomplete-uni-patterns`, so adding a constructor to `Atom` **fails the build** at every unhandled match — the compiler enumerates #12's consumer sites.

- "(+) for U32, U64 … can be extern also" → keep forward-compatible with future `Num`/`(+)` overloading (per-type externs via the existing dictionary mechanism); do not hardcode "`+` is one prim".

-- | Best-effort source position of a pattern: walk to the leftmost positioned
-- leaf. Returns Nothing for bare string/char/wildcard/unit (no position token).
patPos :: Abs.Pat -> Abs.BNFC'Position
patPos (Abs.PAtom ap)        = atomPatPos ap
patPos (Abs.PApp mp _ _)     = Just (modPathPos mp)
patPos (Abs.PCons h _)       = atomPatPos h

atomPatPos :: Abs.AtomPat -> Abs.BNFC'Position
atomPatPos (Abs.APVar (Abs.VarId (p, _)))   = Just p
atomPatPos (Abs.APCon mp)                   = Just (modPathPos mp)
atomPatPos (Abs.APLitI (Abs.WokInt (p, _))) = Just p
atomPatPos (Abs.APTuple p _)                = patPos p
atomPatPos (Abs.APList (p : _))             = patPos p
atomPatPos (Abs.APParen p)                  = patPos p
atomPatPos (Abs.APAs inner _)               = atomPatPos inner
atomPatPos (Abs.PRecord (Abs.ConId (p,_)) _)        = Just p
atomPatPos (Abs.PRecordOpen (Abs.ConId (p,_)) _ _)  = Just p
atomPatPos (Abs.PRecordWild (Abs.ConId (p,_)) _)    = Just p
atomPatPos _                                = Nothing  -- APWild/APLitS/APLitC/PUnit/APList []
