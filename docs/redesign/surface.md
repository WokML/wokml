# wok v2 surface — full theoretical redesign

Companion to `spec.md` (the contract). This file fixes the CONCRETE surface:
keyword palette, sequencing, declaration forms, and the complete expression
grammar sketch. Semantics are the frozen feature set; every form here obeys
the RULES (one-shot law, affinity by inference, second-class carriers,
labeled capability rows, labels-are-not-terms).

## 1. Tone principle (D10)

Two registers, no metaphor:

1. ML SKELETON — where wok is an ordinary ML, the keyword is the ordinary
   word. No novelty spent on familiar ground.
2. LAW WORDS — where wok's discipline departs from ML, the keyword states
   the promise. Reading the keyword teaches the rule.

Rejected register: metaphor (a kitchen-themed palette was considered).
Metaphor words are unsearchable, unpredictable for LLM agents, and spend a
word without stating a law.

The binding rules are generated by two principles (spec 1.0): P1 —
explicitness scales with scope visibility; P2 — lowercase labels are free
ROLES, capitalized names assign per-effect DESIGNATION SLOTS (checked by
ordinary name resolution and typing).

## 2. Keyword palette

| Register | Keywords |
|----------|----------|
| ML skeleton | `module` `import` `as` `type` `alias` `class` `instance` `let` `in` `case` `of` `if` `then` `else` `where` `\` (lambda) |
| Law words | `effect` `handler` `handle` `use` `once` `return` `var` `:=` `with` `foreign` `extern` `own` `lend` `copy` |

Law-word promises:
- `once op args k -> e` — this clause receives the continuation; it resumes
  AT MOST ONCE (checked by inference, declared by the word).
- `handle l = h` — install an activation of handler `h`, binding label `l`;
  binding the effect head name (`handle State = state 0`) serves
  ambient/default-label code. Statement form REQUIRES the label; the
  delimited inline form `handle h in e` may elide it, defaulting to the
  effect head (spec D13, two-tier). Capitalized names assign per-effect
  DESIGNATION SLOTS, checked by ordinary name resolution and typing (spec
  P2, D17); lowercase labels are free role names.
- `use x as l` — re-bind a label, visibly, at a naming boundary.
- `var cur = e` / `cur := e` — state that lives ONLY in a handler frame.
- `return v -> e` — the answer clause (value leaves the handler).
- `own` / `lend` / `copy` — the FFI transfer law on a foreign signature:
  consumed by C / read-only view / duplicated across the boundary.
- `with` — appears ONLY in types: the labeled capability row.

Reserved from op-name position: `once`, `return`, `var` (E-RESERVED).

## 3. Declarations (layout-uniform)

```
module Main
import Base
import Geometry (area, Point) as G

type Color = Red | Green | Blue          -- sum type ("type", Elm-style)
type Point = { x : U64, y : U64 }        -- record (braces = record type only)
alias Weighted = [(U64, U64)]            -- synonym

class Eq a
  (==) : a -> a -> Bool

instance Eq Color
  (==) a b = ...

effect State s                           -- ops in a layout block, no braces
  get : s
  set : s -> ()

foreign module Libc "c"
  strlen : lend Bytes -> U64             -- transfer-none: C reads, may not keep
  free   : own Bytes -> ()               -- transfer-full: C consumes; dead after
  getenv : String -> copy String         -- result duplicated into wok's heap
```

`extern` remains the prelude-only trust anchor for compiler holes; analyses
trust the marker, never name strings.

## 4. Blocks and sequencing (D11)

An indented block is a SEQUENCE. Statement forms:

```
let pat = expr          -- bind; scopes over the REST of the block (no `in`)
handle l = h            -- install, binding label l; scopes over the rest of the block
use x as l              -- re-bind a label; scopes over the rest of the block
_ = expr                -- evaluate and EXPLICITLY discard a non-unit value
expr                    -- a unit-typed line sequences freely
expr                    -- the FINAL line is the block's value
```

The discard law: a non-final, non-unit line without `_ =` is E-DISCARD (an
error, not a warning). Nothing is dropped silently — the surface twin of the
runtime counting every value.

The inline forms `let p = e in e2`, `handle [l =] h in e`, `use x as l in e`
remain for single expressions; the inline handle's label may be elided and
defaults to the effect head (spec 1.2). A statement's right-hand side may itself be a deeper-
indented block.

## 5. Expressions

- Application, operators, sections as in current wok; `$` retained.
- `\x -> e` lambda; multi-clause function heads compile to decision trees;
  `pat as name` as-patterns; `case e of` with layout arms; arm bodies may be
  blocks (column-aware, as shipped).
- `::` is BOTH expression and pattern (cons); `++` is append.
- `class Ord a` ships alongside Eq (same dictionary machinery), giving
  `<  <=  >  >=` — branching on equality-plus-mod ends.
- Function-equation `where` bindings: unchanged from current wok.
- Literals, tuples, records with dot projection: unchanged.
- Dot resolution (spec 1.5): qualifier/label collision is E-LABEL; otherwise
  qualifier > row label > projection.

## 6. Effects (the spec's design, restated on the new surface)

```
state : s -> Handler (State s) a (a, s)
state init = handler State
  var cur = init            -- term binder; the signature's `s` is a TYPE
  get      -> cur           --   variable — separate namespaces
  set x    -> cur := x
  return v -> (v, cur)

transfer : () -> () with (from : State U64) + (to : State U64)
transfer () =
  let amt = from.get
  from.set 0
  to.set (to.get + amt)

main =
  handle from = state 100
  handle to   = state 5
  transfer ()
```

- Rows are labeled, set-based, keyed by name (spec 1.3, D9); `with State U64`
  is a slot obligation, needing and having no written label (slots are
  named by their effect); labeled entries are parenthesized and LOWERCASE
  (spec D20); labels are not terms.
- Handlers are first-class values; the capability exists only as a label.
- `once` clauses bind the continuation as the LAST binder, arity-checked
  (E-ARITY); shadowing a live continuation is E-SHADOW; affinity is inferred,
  never annotated (spec C10).
- Op-argument positions take PATTERNS (spec D14): multiple clauses per op
  dispatch on constructors and desugar to case (decision trees); together
  they must cover the argument type (E-COVER); the continuation binder is
  always a bare variable.
- Coroutines are primitive: `Step`/`Suspension`, `start`/`step`/`run`/
  `cancel`, residual rows in their kinds; `Step` is the sole carrier wrapper
  (spec D16). Suspensions, continuations, and ContCells are the CONSUMING
  (affine) carriers; `Borrow` is second-class but many-read (non-affine).
  All are guarded by the ONE mode checker and the unified diagnostics
  registry (spec sections 2-3).
- A handler whose arm bodies perform carries its own row
  (`Handler E a b with (log : Writer [String])`), discharged at each `handle`
  site like a function's row at a call site (spec 1.1, D15).

## 7. The flagship program (mtl stack, full new surface)

```
module Main
import Base
import Control

type Cmd = Inc U64 | Snapshot | Boom

tick : Cmd -> U64 with Reader U64 + Writer [U64] + State U64 + Except String
tick cmd = case cmd of
  Inc n ->
    State.set (State.get + Reader.ask * n)
    1
  Snapshot ->
    Writer.tell [State.get]
    1
  Boom -> Except.throw "machine hit a Boom"

walk : [Cmd] -> U64 with Reader U64 + Writer [U64] + State U64 + Except String
walk cmds = case cmds of
  []          -> 0
  cmd :: rest -> tick cmd + walk rest

main : Result ((U64, U64), [U64]) String
main =
  handle Except = except
  handle Reader = reader 10
  handle Writer = writer
  handle State  = state 0
  walk [Inc 1, Snapshot, Inc 2, Snapshot]
```

## 8. Wart ledger: what freedom actually changed

| Current wok | v2 | Why |
|-------------|----|-----|
| `let u = State.set x in e` | `State.set x` as a statement | block sequencing; the dummy-binder noise appears in every effectful file |
| `[x] ++ k ()` | `x :: k ()` | cons is an expression now |
| `data Cmd = ...` | `type Cmd = ...` | one common word; `alias` for synonyms |
| `effect E = { op : T }` | layout block | declarations are layout-uniform |
| `with` (4 meanings) | `with` = rows only | D1; `handler`/`handle`/`use` carry the rest |
| equality-only branching | `Ord` + comparison operators | classes already exist; same dictionary road |
| silent value drops possible | `_ = e` required (E-DISCARD) | nothing dropped silently, surface twin of Perceus |

Everything not in this table is deliberately UNCHANGED — three rounds of
pressure testing kept converging back to the current surface (layout, case,
constructors, default-label rows, signatures), which is evidence of a local
optimum, not timidity.
