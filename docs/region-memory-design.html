Scoped regions vs reference counting

How a region frees memory, why plain RC-inside-a-region is slower than a true region, and how escape analysis recovers the speed — without ever building copy-out.

1 · Two questions: where, and when

Memory answers two separate questions. A region (an effect handler’s scratch arena) decides where a value lives; reference counting decides when it dies. Keeping them apart is what makes the safe design safe — and it turns the whole choice into one routing decision at each allocation.

fig 1 — one decision per allocation; the escapee is born in the RC heap, so nothing is ever copied out

2 · Why RC-in-a-region is slower than a true region

RC’s real cost is write traffic: every dup/drop writes an object’s header. At teardown a true region resets one pointer; plain RC must walk every count to zero first.

true region

O(1) free

Reset the bump pointer / return slabs. The whole cohort dies for the price of one operation — zero per-object work.

plain RC

O(N) drops

Every object’s rc walks to 0 — N header writes + branches + cascade — before the slabs come back. Dirties N cachelines.

Shape matters: the gap is large only for deeply-boxed cohorts (trees, lists, a boxed Array a) whose drop cascades into N children. For flat / unboxed data (Array U64, Array Char) the drop is already O(1) — RC and a true region cost the same. In wok this shows up directly: the differential oracle counts frees, so a true region nets O(1) cohort-frees and plain RC nets O(N).

Optimistic & flexible, but needs a deep-copy walker + a fresh soundness proof (novel).

4 · Pick two — and how analysis dissolves it

Without escape analysis, three properties trade off and any single design gets only two. Escape analysis is a third axis: deciding placement per allocation lets you keep escape and simplicity while clawing back the speed for everything it can prove local.

fig 4 — F/R/D each sit on one edge (two vertices, lacking the third); R+escape reaches all three, paying instead in analysis precision

The point: escape analysis is the dial between all-RC (R) and all-skip (F), turned per allocation-site. RC is the floor that keeps it sound; deciding placement up front means copy-out is the one piece of machinery you never have to build.
